# ПИД на роботе по линии — анимации Manim

Анимации для курса: робот на Iskra Uno едет по линии с ПД-регулятором. Шесть сцен — от команд моторам до
перекрестка; видео идут на слайды презентации, кадры — в репозиторий уроков.

- `docs/spec.md` — решения и сюжет сцен; `docs/architecture.md` — как устроен код; `docs/measurements.md` — замеры
  машинки и откуда числа в модели.
- Сцена — кнопка ▶ в файле `scenes/…py` (видео 480p в `videos/`).
- Все видео 1080p и картинки уроков — `python scenes/lessons.py` (видео в `videos/`, картинки в `renders/lessons/`);
  черновик — `python scenes/lessons.py 480p`.
- Тесты — `python -m pytest -q`; подбор kp и kd по модели — `python tune.py`.

Шрифты Segoe UI и Consolas — как на слайдах; финальный рендер — на Windows (на Linux подставляются похожие).
