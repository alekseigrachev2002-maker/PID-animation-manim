# Как устроен проект

Сначала физика считает траекторию, потом сцена ее проигрывает.

```
params.py   все числа: робот, датчики, моторы, регулятор, цвета, макет кадра
track.py    трасса: Track(Route(...).forward(...).right(R=...)), метки, поза на линии
model.py    физика: датчики → err → регулятор → ШИМ → моторы → движение; simulate() → Trajectory
            (таблица по времени: поза, путь колес, L, R, err, uP, uD, ШИМ); prescribed()/move() — движение «руками»

visuals/layout.py  перевод пикселей и мм в единицы Manim, текст, фон
visuals/camera.py  камера: follow (робот в одной точке экрана, поле едет) или fixed (поле стоит, робот ездит)
visuals/field.py   линии трассы на экране
visuals/robot.py   робот: place(точка, курс), протектор, метки датчиков; Robot(sensors=False) — без датчиков
visuals/panel.py   панель графиков: шапка, блок формулы, график сигналов, легенда, доп. легенда (ШИМ колес)

scenes/base.py     PIDScene — стенд: время t, show(трасса, траектория, камера, элементы), advance, return_to
                   RunSeries — серия прогонов: прогон → стоп → возврат → следующий
scenes/s*.py       сцены
```

Каждый кадр стенд берет состояние траектории в момент t и раздает его камере, полю, роботу и элементам
(например строке ШИМ). Кривые на графике сами дорисовываются до t.
Правило непрерывности: каждый кусок траектории начинается и кончается в покое (единственный стык «на ходу» —
прогон → торможение, где торможение продолжает прогон с теми же скоростями колес). Так скорость нигде не прыгает.
- `model.simulate` — регулятор, старт с места; `stop_below` — конец на перекрестке (L и R ниже порога);
- `model.brake` — motors(0, 0) до полной остановки; команды, еще идущие по задержке, доезжают до колес;
- `model.chain` — склейка отрезков в одну траекторию (график через всю сцену, сцена 3);
- `model.drive(pwm=(лев, прав))` — езда с постоянным ШИМ колес с места (для сцены 0);
- `model.move` / `prescribed` — движение «рукой» (перестановка, качание), с плавным началом и концом.
`switch()` проверяет каждый стык и предупреждает о скачке скорости или вращения.

## Новая сцена с прогонами регулятора
```python
class Scene2c(RunSeries):
    phrase, formula, law = "Вводим D", "control = kp·err + kd·Δerr", "control"
    formula_colors = [("kp·err", "e"), ("kd·Δerr", "D")]
    signals = [Signal("uP", "uP", "e"), Signal("uD", "uD", "D")]
    runs = [(dict(kp=0.3, kd=0), "без D"), (dict(kp=0.3, kd=2), "с D")]

    def make_track(self):
        return Track(Route(start=(0, -1500), heading="вверх").forward(1500).mark("поворот").right(R=100).forward(1500))

    def start(self, i):
        return self.track.pose("поворот", -350)
```
Сцена без регулятора (как сцена 1) — `PIDScene`: своя траектория, `self.show(...)`, `GraphPanel(...)`, `self.advance(...)`.

## Проверка
`python -m pytest -q` — физика. Кадр сцены — `render(Scene, "1080p", still=True)`; видео в 4K — `render(Scene, "4k")`, все в `videos/`.

## Картинки для уроков
`scenes/lessons.py` — кнопка ▶ (или `python scenes/lessons.py`): картинки для репозитория уроков в `renders/lessons/`.
- PNG 1280×720 — по одной на сцену: `scene-0-motion`, `scene-1-error`, `scene-2a-p`, `scene-2b-turn`, `scene-2c-d`,
  `scene-3-cross`.
  Момент кадра — в списке `KEYS` (секунды видео сцены 1080p); поменять картинку — поменять число. Кадр
  вырезается из видео по времени, поэтому при перерендере не съезжает.
- Сцена 3 — особый кадр: `Scene3Key` (там же) рисует тот же стоп, но график — только езда и стоп, без провала
  правого датчика при развороте на линию. Видео сцены 3 не меняется.
- Кадры — через PyAV (стоит вместе с Manim), внешний ffmpeg не нужен. Скрипт печатает размеры и отмечает
  картинки больше цели (~300 КБ). Видео для уроков скрипт не делает.
- Подобрать момент удобно по кадрам видео: `ffmpeg -i videos/Scene1_720p.mp4 -vf fps=2,tile=6x5 sheet.png`.
