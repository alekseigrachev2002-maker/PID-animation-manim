# Как устроен проект

Сначала физика считает траекторию, потом сцена её проигрывает.

```
params.py   все числа: робот, датчики, моторы, регулятор, цвета, макет кадра
track.py    трасса: Track(Route(...).forward(...).right(R=...)), метки, поза на линии
model.py    физика: датчики → err → регулятор → ШИМ → моторы → движение; simulate() → Trajectory
            (таблица по времени: поза, путь колёс, L, R, err, uP, uD, ШИМ); prescribed()/move() — движение «руками»

visuals/layout.py  перевод пикселей и мм в единицы Manim, текст, фон
visuals/camera.py  камера: follow (робот в одной точке экрана, поле едет) или fixed (поле стоит, робот ездит)
visuals/field.py   линии трассы на экране
visuals/robot.py   робот: place(точка, курс), протектор, метки датчиков; Robot(sensors=False) — без датчиков
visuals/panel.py   панель графиков: шапка, блок формулы, график сигналов, легенда, доп. легенда (ШИМ колёс)

scenes/base.py     PIDScene — стенд: время t, show(трасса, траектория, камера, элементы), advance, return_to
                   RunSeries — серия прогонов: прогон → стоп → возврат → следующий
scenes/s*.py       сцены
```

Каждый кадр стенд берёт состояние траектории в момент t и раздаёт его камере, полю, роботу и элементам
(например строке ШИМ). Кривые на графике сами дорисовываются до t.
Правило непрерывности: каждый кусок траектории начинается и кончается в покое (единственный стык «на ходу» —
прогон → торможение, где торможение продолжает прогон с теми же скоростями колёс). Так скорость нигде не прыгает.
- `model.simulate` — регулятор, старт с места; `stop_below` — конец на перекрёстке (L и R ниже порога);
- `model.brake` — motors(0, 0) до полной остановки; команды, ещё идущие по задержке, доезжают до колёс;
- `model.chain` — склейка отрезков в одну траекторию (график через всю сцену, сцена 3);
- `model.drive(pwm=(лев, прав))` — езда с постоянным ШИМ колёс с места (для сцены 0);
- `model.move` / `prescribed` — движение «рукой» (перестановка, качание), с плавным началом и концом.
`switch()` проверяет каждый стык и предупреждает о скачке скорости или вращения.

## Новая сцена с прогонами регулятора
```python
class Scene2c(RunSeries):
    phrase, formula, law = "Вводим D", "control = kp·err + kd·Δerr", "control"
    formula_colors = [("kp·err", "e"), ("kd·Δerr", "D")]
    signals = [Signal("uP", "uP", "e"), Signal("uD", "uD", "D")]
    runs = [(dict(kp=0.3, kd=0), "без D"), (dict(kp=0.3, kd=2), "с D")]

    def make_track(self):
        return Track(Route(start=(0, -1500), heading="вверх").forward(1500).mark("поворот").right(R=100).forward(1500))

    def start(self, i):
        return self.track.pose("поворот", -350)
```
Сцена без регулятора (как сцена 1) — `PIDScene`: своя траектория, `self.show(...)`, `GraphPanel(...)`, `self.advance(...)`.

## Проверка
`python -m pytest -q` — физика. Кадр сцены — `render(Scene, "1080p", still=True)`; видео в 4K — `render(Scene, "4k")`, всё в `videos/`.

## Картинки и видео для уроков
Каждая сцена знает свой ключевой кадр — картинку, по которой без видео понятно, что происходит:
- `key_time = 23.5` — момент видео в секундах; `render(Scene, "720p", key=True)` рендерит видео, если его нет,
  и вырезает кадр через ffmpeg (`-ss` после `-i` — точный кадр, при перерендере не съезжает). Сцены 0, 1, 2a–2c.
- `key = True` в режиме ключевого кадра — сцена собирает картинку сама, это последний кадр в этом режиме; видео
  его не видит. Сцена 3: на графике только езда и стоп, без провала датчика при развороте на линию.

Результат `render(..., key=True)` — `renders/<Сцена>_<качество>_key.png`. Поменять картинку — поменять `key_time`
в сцене (подобрать момент удобно по кадрам видео: `ffmpeg -i videos/Scene1_720p.mp4 -vf fps=2,tile=6x5 sheet.png`).

Всё для репозитория уроков — одной командой: `python lessons.py` (или ▶ в `lessons.py`). Плоская папка
`out/lessons/`: `scene-0-motion`, `scene-1-error`, `scene-2a-p`, `scene-2b-turn`, `scene-2c-d`, `scene-3-cross` —
`.png` 1280×720 (ключевой кадр из 1080p) и `.mp4` 720p без звука, H.264 CRF 26, `+faststart`. Скрипт печатает
размеры и отмечает файлы больше цели (PNG ~300 КБ, mp4 ~4 МБ).
