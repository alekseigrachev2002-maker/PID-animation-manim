# Как устроен проект

Сначала физика считает траекторию, потом сцена ее проигрывает.

```
params.py   все числа: робот, датчики, моторы, регулятор, дальномер (Sonar), цвета, макет кадра
track.py    трасса: Track(Route(...).forward(...).right(R=...)), метки, поза на линии; разметка и предметы поля:
            squares (желтые квадраты), discs (черные круги), blocks (кубики, Block); field1() — поле 1
model.py    физика: датчики → err → регулятор ПИД → ШИМ → моторы → движение; simulate() → Trajectory
            (таблица по времени: поза, путь колес, L, R, err, uP, uD, uI, integral, ШИМ); prescribed()/move() —
            движение «рукой»; sonar_distance() — дальномер; bisect()/fit_run() — подбор времени и угла
tune.py     подбор kp и kd по модели алгоритмом урока (поворот сцены 2b); печатает каждый шаг

visuals/layout.py  перевод пикселей и мм в единицы Manim, текст (шрифт — первый найденный из списка), фон
visuals/camera.py  камера: follow (робот в одной точке экрана, поле едет) или fixed (поле стоит, робот ездит);
                   rot — поворот на всю сцену
visuals/field.py   линии трассы, разметка, черные круги и кубики на экране
visuals/robot.py   робот: place(точка, курс), протектор, метки датчиков; Robot(sensors=False) — без датчиков;
                   SonarRobot — с дальномером HC-SR04 в креплении
visuals/panel.py   панель графиков: шапка (заголовок, формула, пояснение), график, легенда, строка ШИМ колес;
                   RateLabel — пометка ускорения «×3,0»

scenes/base.py     GENERAL, PLAYBACK, HAND — замедление; BLOCK — длина промежутка сцены; MOTION — подсцена;
                   render() — кнопка ▶
                   PIDScene — стенд: время t, show(трасса, траектория, камера, элементы), advance, switch, return_to;
                   атрибуты sensor, robot_cls, rot, fast, panel_bg; advance_fast (ускорение), hand_to («рука»),
                   begin_segment / end_segment (подсцены)
                   RunSeries — серия прогонов: прогон → стоп → возврат → следующий (промежутки BLOCK)
                   MotionRunSeries — то же по подсценам: прогон с докатыванием — MOTION, «рука» — сверх
scenes/s*.py       сцены 0, 1, 2a, 2b, 2c, 3
scenes/lessons.py  видео всех сцен и картинки для уроков и презентации

tests/test_model.py  физика: датчики, моторы, кинематика, регулятор, стыки траекторий
tests/test_panel.py  правила панели и сцен: сдвиг кривых, текст в шапке, разворот на 180°, прогон «только P»
tests/test_engine.py ПИД с И, счет перекрестков, ускорение, дальномер, поворот камеры

Arduino-Robotics-Lesson/  курс на Nano: nano_track.py (трек Short Track, датчики, отметки маршрута),
                   nano_base.py (сцена с датчиками курса и камерой «старт вверх»), сцены n*.py, nano_lessons.py
```

Каждый кадр стенд берет состояние траектории в момент t и раздает его камере, полю, роботу и элементам
(например строке ШИМ). Кривые на графике сами дорисовываются до t.

Правило непрерывности: каждый кусок траектории начинается и кончается в покое (единственный стык «на ходу» —
прогон → торможение, где торможение продолжает прогон с теми же скоростями колес). Так скорость нигде не прыгает;
`switch()` проверяет каждый стык и предупреждает о скачке скорости или вращения.
- `model.simulate` — регулятор, старт с места; `stop_below` — конец на перекрестке (L и R ниже порога);
- `model.cached_simulate` — то же с кэшем в `.cache/` (ключ — параметры и текст `model.py`);
- `model.brake` — motors(0, 0) до полной остановки; команды, еще идущие по задержке, доезжают до колес;
- `model.drive(pwm=(лев, прав))` — езда с заданным ШИМ колес с места (сцена 0);
- `model.chain` — склейка отрезков в одну траекторию (график через всю сцену, сцена 3);
- `model.move` / `prescribed` — движение «рукой» (перестановка, качание), с плавным началом и концом.

## Новая сцена с прогонами регулятора

```python
class Scene2c(RunSeries):
    phrase = "Вводим D"
    formula = "control = err * kp + (err - errOld) * kd"          # строка из скетча
    formula_colors = [("err * kp", "e"), ("(err - errOld) * kd", "D")]
    signals = [Signal("uP", "uP", "e"), Signal("uD", "uD", "D")]
    runs = [(dict(kp=0.1, kd=0.0), "kd = 0, вылет"), (dict(kp=0.1, kd=1.0), "kd = 1, прошел")]
    # runs = [(0.15, "...")] — одно число: только P (kd = 0)

    def make_track(self):
        return Track(Route(start=(0, -1500), heading="вверх").forward(1500).mark("поворот").right(R=150).forward(1500))

    def start(self, i):
        return self.track.pose("поворот", -350)
```

Сцена без регулятора (как сцены 0, 1, 3) — `PIDScene`: своя траектория, `self.show(...)`,
`GraphPanel(..., formula=...)`, `self.add(panel)`, `self.play(panel.intro(), run_time=0.8)`, `self.advance(...)`.
Смена текста — `panel.set_text(formula, colors, caption)`. Сцена делится на промежутки `BLOCK`: в конце
каждого — `self.end_block()` (ждет до границы; если промежуток длиннее — предупреждение при рендере).

## Возможности для сцен нового курса (в движке)

- **Регулятор ПИД**: `model.simulate(..., ki=0.004)`; ki = 0 — ПД олимпиадного курса. В траектории — uI и integral.
- **Перекрестки**: `stop_below` (порог) и `stop_at` (на каком по счету остановиться); счет по фронту, как в уроке 3,
  перекресток под датчиками на старте не считается. `lost_dist=np.inf` — потерявший линию робот едет дальше.
- **Поле**: `Track(..., discs=[...], blocks=[Block(...)])` — черные круги и кубики; рисует их `Field`.
- **Камера**: `rot` сцены — поворот на всю сцену; `rot = "start"` — стартовый курс робота смотрит вверх.
- **Робот**: `robot_cls = SonarRobot` — с дальномером; что он видит — `model.sonar_distance(поза, track.blocks)`.
- **Время**: `BLOCK` + `end_block()` (сцена ровно N·BLOCK, олимпиадный курс) или подсцены `MOTION` +
  `begin_segment()` / `end_segment()` (моменты концов — в `SEGMENTS`, по ним вырезаются картинки уроков).
- **Ускорение**: `advance_fast(t, zones)` — простая езда в `fast` раз быстрее вне зон, переход по EMA
  (`FAST_TAU`), пометка `RateLabel` «×k».
- **«Рука»**: `hand_to(поза)` — одна скорость для всех сцен (`HAND_V`, `HAND_W`).
- **Фон**: `panel_bg = False` — поле на весь кадр (вид 16:9 без графика).

## Запуск и проверка

- Сцена — кнопка ▶ в ее файле: видео 480p в `videos/<Сцена>_480p.mp4`; там же закомментирован вариант 1080p.
  `render(Scene, "1080p", still=True)` — только последний кадр в `renders/`.
- `python -m pytest -q` — тесты.
- `python tune.py` — подбор kp и kd по модели (несколько минут).

## Видео и картинки для уроков и презентации

`scenes/lessons.py` — кнопка ▶ или `python scenes/lessons.py`: видео 1080p всех шести сцен в `videos/` и картинки
в `renders/lessons/`. Черновик быстрее: `python scenes/lessons.py 480p`.
- Картинки PNG 1920×1080 (как видео), по одной на сцену: `scene-0-motion`, `scene-1-error`, `scene-2a-p`, `scene-2b-turn`,
  `scene-2c-d`, `scene-3-cross`. Они же — кадры-превью видео в презентации (Видео → Кадр-постер → Изображение
  из файла).
- Момент кадра — в списке `KEYS`, через промежутки: «конец промежутка k минус 0.5 с» (одинаков в любом качестве
  и не едет от правок внутри промежутка). Поменять картинку — поменять число.
- Сцена 3 — особый кадр: `Scene3Key` рисует тот же стоп, но график — только езда и стоп, без провала правого датчика
  при развороте на линию. Панель у нее общая со сценой 3 (`Scene3.panel`). Ее видео служебное и удаляется.
- Кадры — через PyAV (стоит вместе с Manim), внешний ffmpeg не нужен. Скрипт печатает размеры и отмечает
  картинки больше цели (~300 КБ).
