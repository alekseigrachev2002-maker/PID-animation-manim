## Кто и зачем
Алексей — магистрант-физик, автор курса по Arduino («Электротехника 8–9») для частной школы, сам ведёт уроки. Делает презентацию о ПИД-регуляторе на своём роботе, который едет по линии. Анимации Manim вставляются между слайдами: на слайдах идея и полная блок-схема со словами, в анимации — короткая фраза этапа, одна формула, график и робот.

## Приложенные файлы
- **`ПИД-анимации — спецификация.md`** — все принятые решения: макет, геометрия, регулятор, модель, архитектура, сцены, открытые вопросы. **Главный источник; при расхождении верен он.**
- **`Chassis.dxf`** — шасси (мм): круг Ø160, вырезы под колёса, крепёжные отверстия. Рисуем без отверстий.
- **SVG платы датчика** (EasyEDA, `PCB_PullDown`): плата 40×10 мм, TCRT5000, отверстия Ø3. Координаты отверстий в SVG верные (масштаб 0.254 мм на единицу).
- **`lesson-02-line-sensors.txt`** — скетч с `followLine()`: `e = L·balance − R`, `u = kp·e + kd·(e − errOld)`, `motors(speed − u, speed + u)`.

## Последние уточнения (в спецификации есть, но легко упустить)
- **Шапка:** фраза этапа из 2–4 слов («Подбираем P») и один блок с текущей формулой, не полоса из пяти блоков. Обозначения как в коде: `u`, `kp`, `kd`.
- **Сюжет D:** P ставим чуть ниже порога раскачки. На плавных поворотах его хватает, на резких — нет, D доделывает. Трасса — прямоугольник с разными скруглениями: два плавных (R ≈ 200–250 мм) и два резких (R ≈ 50–60 мм). На графике uP и uD отдельно.
- **Мёртвую зону ШИМ не убирать:** в поворотах внутреннее колесо в неё проваливается.
- **scipy использовать:** `erf` для гауссова пятна датчика, `cKDTree` для расстояния до линии, `solve_ivp` между тиками регулятора (ZOH) с `dense_output`.
- **Шум датчика** — параметр, по умолчанию 0.
- **Сцена 3** — перекрёсток. И-часть не нужна.
